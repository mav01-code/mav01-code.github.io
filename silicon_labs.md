## Experience

### OA - Online Assessment (on HackerEarth) - 1 hour

It consisted of 3 MCQ's, 9 subjective questions, 3 coding questions. All the MCQ's are based on C language, we were given code snippets and asked to select correct answer for output, error. Subjective questions are based on core ECE - microprocesser, microcontroller, RTOS, Watchdog timer, uP, mP, why is C preferred over Python, Java and other popular languages for hardware operations. 2 coding questions can be written in any programming language while 3rd one needs be in C or C++. For some reason, even though the code is correct, it's not giving correct output. But after submitting, I found out it contained only 1 testcase which is sample testcase given in each coding question description. I simply wrote print statements and it was accepted.

### Technical Interview - 1

Interviewer came a bit late 'cause he got confused between IARE & MLRIT and went to the other college. During the interview, I was asked about my projects, OSI model, TCP - UDP protocol differences, DNS Resolution (what it is and how it happens), Real time example of OSI workflow using Gmail (send a mail), reverse a string using Python ([::-1] and traverse string from end, was asked to write on paper), File handling using Python (create a file, write contents to file, read the file and print number of lines, was asked to write on paper), dictionary syntax, how to access values using keys (write a program on interviewers laptop), shrink in Python, asked about Wireshark. After 2 hours, they gave results for 1st interview and I was selected among 6 students.

### Technical Interview - 2

I was asked about my projects and about the skills I mentioned on my resume. Dictionary, list and tuple syntax in Python (was asked to write on paper), CI/CD, Jenkins, GPIO, Microprocessor, Microcontroller, GEN AI Understanding, Difference between AI and ML. No coding question. I knew I wasn't getting selected 'cause the interview lasted very less minutes and was very boring. Interviewer was not asking any questions and is just asking me to explain how I learnt any specific thing I mentioned on resume. Interaction was very less. At the end, he asked which interview felt better to which I answered 1st one.
